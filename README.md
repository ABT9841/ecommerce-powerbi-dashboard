E-Commerce Analytics Dashboard (Power BI)
Project Overview

Built an interactive Power BI dashboard using the Olist E-Commerce dataset to analyze sales performance, customer behavior, product performance, delivery efficiency, and payment trends.

Business Questions
How has revenue changed over time?
Which product categories generate the most revenue?
Which states contribute the most sales?
What factors impact customer reviews?
How effective is customer retention?

Key Insights
Revenue exceeded $15.8M across 98K orders.
Health & Beauty generated the highest revenue.
Repeat customers represented only 3% of customers.
Faster deliveries received higher review ratings.
Cancellation rate remained below 1%.
